# Licence texts

Each plugin folder carries its upstream licence (`LICENSE`, `NOTICE`, ...) where the upstream project ships one. Some
Schwung modules only declare their licence in `src/module.json`; for those, the full texts are here:

- [`GPL-3.0.txt`](GPL-3.0.txt): GNU General Public License v3 (303, Hera, OB-Xd)
- [`GPL-2.0.txt`](GPL-2.0.txt): GNU General Public License v2 (Noisemaker / TAL-NoiseMaker)
- MIT (Braids, Hank, Moog, Mr Drums, Mr Hyde): the MIT terms, with the copyright of the authors named in the plugin's
  README and `src/module.json`.

Hush One and Libpo32 state no licence upstream; see their READMEs.
